# فلورا — متجر ورد أونلاين

| الجزء | التقنية | الفولدر |
|---|---|---|
| الموقع (اللي العميل بيشوفه) | Next.js 16 + Tailwind CSS 4 | `frontend/` |
| الـ API والداش بورد | Laravel 12 + Filament 5 | `backend/` |

## التشغيل على جهازك

```bash
# 1) الباك إند
cd backend
composer install
cp .env.example .env        # أول مرة بس
php artisan key:generate    # أول مرة بس
php artisan migrate --seed  # بيعمل الجداول + داتا تجريبية + حساب أدمن
php artisan storage:link
php artisan serve           # http://localhost:8000

# 2) الفرونت إند (ترمينال تاني)
cd frontend
npm install
cp .env.example .env.local  # وحط نفس REVALIDATE_SECRET اللي في backend/.env
npm run dev                 # http://localhost:3000
```

- **الموقع:** http://localhost:3000
- **الداش بورد:** http://localhost:8000/admin
  - الإيميل: `admin@flora.test` | الباسورد: `password` ← **غيّرهم فوراً** من صفحة البروفايل

> لازم `FRONTEND_REVALIDATE_SECRET` في `backend/.env` يبقى نفس `REVALIDATE_SECRET` في `frontend/.env.local`،
> عشان أي تعديل من الداش بورد يظهر على الموقع في نفس اللحظة.

## اللغات (عربي + English)

- العربي هو الأساسي على الروابط العادية: `/products/بوكيه-روز-بينك`
- الإنجليزي تحت `/en`: `/en/products/pink-roses-bouquet`
- كل فورم في الداش بورد فيه تاب **العربي** وتاب **English**. لو سبت الإنجليزي فاضي، بيظهر العربي مكانه.
- الطلب بيتسجل بلغة العميل (بتظهر في الداش بورد)، ورسائل الأخطاء بتطلع بلغته.
- نصوص الموقع الثابتة (الأزرار والعناوين) في `frontend/src/i18n/dictionaries.ts`.

## تتبع الطلب

- تاب "تتبع طلبك" ظاهرة دايماً في الهيدر.
- العميل بيكتب رقم الطلب ورقم الموبايل ويشوف خط زمني بكل مرحلة ووقتها (استلمنا ← تم التأكيد ← بنجهز ← في الطريق ← اتسلم).
- الطلبات بتتحفظ على جهاز العميل، فيقدر يرجع يتابعها بضغطة من غير ما يكتب حاجة، والصفحة بتتحدث لوحدها كل دقيقة.
- أي تغيير في حالة الطلب من الداش بورد بيتسجل بوقته، وبيظهر للعميل على طول.

## إزاي أتحكم في الموقع؟

| عايز تعمل إيه | تروح فين في الداش بورد |
|---|---|
| صور السلايدر (رفع صور كتير مرة واحدة، ترتيب بالسحب، كلام وزرار على كل صورة) | الصفحة الرئيسية ← **السلايدر** |
| سرعة وارتفاع السلايدر، التقليب التلقائي، الأسهم والنقط | السلايدر ← زرار **إعدادات السلايدر** |
| بانر في الرئيسية / فوق منتجات تصنيف / صفحة المنتج / السلة / أعلى كل الصفحات | الصفحة الرئيسية ← **البانرات** ← بانر جديد ← اختار "يظهر فين" |
| ترتيب أقسام الرئيسية، إضافة قسم (منتجات، آراء، أسئلة، فيديو...) | الصفحة الرئيسية ← **ترتيب أقسام الرئيسية** |
| صفحة "من نحن" والسياسات | المحتوى ← **الصفحات** |
| الألوان، اللوجو، روابط القائمة والفوتر | الإعدادات ← **الشكل والألوان والقائمة** |

- في كل صورة سلايدر أو بانر بتتحكم في: **مكان الكلام** (يمين / النص / شمال)، **لونه** (أبيض / غامق)، **غمقان الصورة**، الزرار والرابط، وفترة الظهور (يبدأ وينتهي في ميعاد).
- البانر بتختار **عرضه** (كامل / نص / تلت) و**ارتفاعه**. البانرات "نص العرض" ورا بعض بتظهر جنب بعض.
- أي بانر مكانه "الصفحة الرئيسية" بيظهر في قسم "بانرات" على طول.

## الداش بورد فيها إيه؟

- **الرئيسية:** إحصائيات، رسم بياني للمبيعات آخر 30 يوم، الأكثر مبيعاً، وآخر الطلبات
- **إشعارات (الجرس 🔔)** بكل طلب جديد

- **الطلبات:** تبويبات حسب الحالة و"توصيل النهارده"، وتغيير الحالة، ورسالة الكارت، وبيانات المرسل والمستلم، وسكرين شوت التحويل، وزرار واتساب للعميل، وطباعة الطلب مع الكارت في صفحة لوحده
- **المنتجات:** صور متعددة، سعر وخصم، أكتر من تصنيف، مواصفات، إظهار/إخفاء، متاح/غير متاح، نسخ منتج، SEO لكل منتج
- **التصنيفات:** تصنيفات رئيسية وفرعية، صورة وبانر، ونص SEO أسفل الصفحة
- **الصفحة الرئيسية:** تضيف أي سكشن (سلايدر، تصنيفات، منتجات، بانر، مجموعة بانرات، مميزات، نص، آراء عملاء، أسئلة شائعة) وترتبهم بالسحب
- **الصفحات:** من نحن، سياسة الاسترجاع، وأي صفحة جديدة
- **الإعدادات:** الاسم واللوجو، التواصل والسوشيال، SEO و Google Analytics و Search Console و Facebook Pixel، حسابات التحويل، مواعيد التوصيل، الحد الأدنى للطلب
- **مناطق التوصيل** ورسوم كل منطقة، و**مستخدمين الداش بورد**

## SEO

- كل صفحة بتتبعت لجوجل HTML كامل (Server-side rendering + cache)
- عنوان ووصف و canonical و Open Graph لكل صفحة (ممكن تعدلهم من الداش بورد)
- Schema.org: `Florist`, `WebSite` (بحث)، `Product` + `Offer` (السعر يظهر في جوجل)، `BreadcrumbList`، `FAQPage`، `CollectionPage`
- `sitemap.xml` بيتحدّث لوحده (فيه صور المنتجات) و `robots.txt`
- روابط عربية نضيفة: `/products/بوكيه-روز-بينك`
- باجنيشن بروابط حقيقية، وصفحات البحث والفلترة `noindex` عشان ما يبقاش فيه محتوى مكرر
- صور بتتحول لـ AVIF/WebP وبمقاسات مناسبة للموبايل

## الرفع على السيرفر (ملخص)

1. **الباك إند** على أي استضافة PHP 8.2+ و MySQL. في `.env` غيّر:
   `APP_ENV=production`، `APP_DEBUG=false`، `APP_URL=https://api.your-domain.com`،
   `DB_CONNECTION=mysql` وبيانات الداتا بيز، `FRONTEND_URL=https://your-domain.com`
   وبعدين: `php artisan migrate --force && php artisan storage:link && php artisan optimize`
2. **الفرونت إند** على Vercel أو VPS عليه Node.js 20+:
   `NEXT_PUBLIC_API_URL=https://api.your-domain.com`، `NEXT_PUBLIC_SITE_URL=https://your-domain.com`، `REVALIDATE_SECRET=...`
   وبعدين: `npm run build && npm start`
3. سجّل الموقع في **Google Search Console**، وحط كود التأكيد في الإعدادات ← SEO، وابعت `https://your-domain.com/sitemap.xml`.
